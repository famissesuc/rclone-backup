対象と目的

rclone-backup は、本人が管理する端末から本人の Google Drive へ、restic と rclone を使ってバックアップを保存・復元する個人用アプリです。第三者の利用者を募集するサービスではありません。

アクセスするデータと利用

本人が選択したローカルデータを restic で暗号化し、rclone を通じて Google Drive に保存します。Google Drive API の drive.file 権限により、このアプリが作成したファイル、または本人がこのアプリに利用を許可したファイルの内容とメタデータを、バックアップの保存・確認・復元・管理のために読み書きします。

Google の認可情報は端末側で rclone が接続のために使用します。認可情報やバックアップの内容を、この説明サイトへ送信する機能はありません。

保管と共有

暗号化バックアップは本人の Google Drive に保管します。復元に必要な暗号化パスワードは本人が管理します。端末側では処理に必要なキャッシュや実行ログが保存される場合があります。本アプリの目的として、Google API から取得したデータを販売したり、広告・AIモデルの学習に利用したり、第三者向けに公開・配布したりしません。

保持と削除

バックアップは、本人が削除または保持設定に基づく整理を行うまで保管します。不要なスナップショットや保存データは、本人が restic の保持・削除機能や Google Drive の管理機能で削除できます。Google Drive のゴミ箱に移したデータの完全削除は、同サービスの仕組みに従います。端末側の認可情報・キャッシュ・ログは、必要に応じて本人が別途削除します。

Google アカウントへのアクセス取消

本人は Google アカウントの接続管理から、本アプリへのアクセスを取り消せます。取消後は再度許可するまで接続できません。アクセスの取消だけでは、すでに保存したバックアップは削除されません。

このウェブサイトについて

このサイトは GitHub Pages 上の静的な説明ページです。独自のアクセス解析、広告、入力フォーム、Cookie を使用するコードは設置していません。ホスティング事業者の GitHub は、サイト配信やセキュリティ等のために IP アドレスなどのアクセス情報を扱うことがあります。これはバックアップアプリによる Google Drive データの取扱いとは別です。詳細は GitHub のプライバシー声明をご覧ください。
